# 🛡️ SiteGuard | حارس موقعك

خدمة اشتراك شهري (SaaS) تراقب أمان مواقع الشركات الصغيرة تلقائيًا وترسل تنبيهات بالبريد مع خطوات الإصلاح.
تعمل لوحدها بالكامل بعد التشغيل: العميل يسجل، يثبت ملكية موقعه، يدفع عبر Stripe، والفحوص والتنبيهات تعمل يوميًا بدون تدخل منك.

## ماذا تفحص؟

| الفحص | لماذا يهم العميل |
|---|---|
| صلاحية شهادة SSL وموعد انتهائها | انتهاء الشهادة يوقف الموقع ويطرد الزوار |
| التحويل من HTTP إلى HTTPS | حماية بيانات الزوار |
| ترويسات الأمان (HSTS, CSP, X-Frame-Options, nosniff, Referrer-Policy) | حماية من XSS و Clickjacking |
| كشف رقم إصدار السيرفر | يسهّل على المهاجمين استهداف ثغرات معروفة |
| ملفات حساسة مكشوفة (`.git`, `.env`, نسخ قواعد بيانات) | أخطر تسريب شائع في المواقع الصغيرة |
| سجلات SPF و DMARC | منع انتحال بريد الشركة في رسائل احتيال |

كل نتيجة لها درجة خطورة، ويُحسب تقييم من 100، ويصل للعميل بريد فقط عند ظهور مشكلة **جديدة**.

## قانونية وأخلاقية

- لا يُفحص أي نطاق قبل أن يثبت صاحبه ملكيته بإضافة سجل DNS من نوع TXT (`_siteguard.<domain>`).
- الفحوص سلبية وخفيفة (زيارة عادية + استعلامات DNS عامة)، بدون أي محاولة اختراق أو ضغط على السيرفر.
- حماية من SSRF: يرفض أي نطاق يشير لعناوين داخلية أو خاصة.
- التطبيق نفسه يطبّق ترويسات الأمان التي ينصح بها، ويستخدم CSRF وتشفير كلمات المرور.

## التشغيل محليًا

```bash
pip install -r requirements.txt
python -m pytest            # تشغيل الاختبارات
python -m siteguard.app     # الموقع على http://localhost:8000
python -m siteguard.monitor # عامل الفحص اليومي
```

## النشر (مرة واحدة ثم يعمل لوحده)

1. انسخ `.env.example` إلى `.env` واملأ القيم.
2. على أي سيرفر VPS رخيص (حوالي 5 دولار شهريًا: Hetzner أو DigitalOcean) شغّل:
   ```bash
   docker compose up -d --build
   ```
   هذا يشغّل الموقع وعامل الفحص الذي يعيد فحص كل النطاقات كل 24 ساعة.
3. ضع أمامه Caddy أو Cloudflare لشهادة HTTPS مجانية.
4. **الدفع:** في Stripe أنشئ منتجين اشتراك (9$ و 29$ شهريًا) كـ Payment Links، وضع الروابط في `.env`. ثم أضف Webhook على `https://your-domain.com/stripe/webhook` للأحداث `checkout.session.completed` و `customer.subscription.deleted`. الترقية والإلغاء يحدثان تلقائيًا.
5. **البريد:** أي خدمة SMTP (Brevo مجانية حتى 300 رسالة يوميًا).

## خطة الدخل

| الباقة | السعر | النطاقات |
|---|---|---|
| مجاني | 0$ | 1 (لجذب العملاء) |
| احترافي | 9$/شهر | 5 |
| أعمال | 29$/شهر | 25 (للوكالات ومطوري المواقع) |

- **أرقام واقعية:** 100 مشترك احترافي = 900$ شهريًا. 20 وكالة على باقة الأعمال = 580$ إضافية. التكلفة تقريبًا 10$ شهريًا (سيرفر + دومين).
- **أفضل العملاء:** وكالات تصميم المواقع ومطورو ووردبريس، لأنهم يديرون عشرات المواقع ويريدون تقريرًا يطمئن عملاءهم.
- **جلب العملاء بدون مجهود مستمر:**
  1. الباقة المجانية نفسها تسويق: كل تقرير يكشف مشاكل تدفع للترقية.
  2. مقالات عربية وإنجليزية عن "كيف تحمي موقعك من انتحال البريد" و"ماذا يحدث لو انتهت شهادة SSL" تجلب زيارات من جوجل.
  3. عرض في مجموعات أصحاب المتاجر الإلكترونية (سلة، زد، شوبيفاي) ومنصات مثل Product Hunt.

## البنية

```
siteguard/
  checks.py   الفحوص الأمنية السلبية + حماية SSRF
  verify.py   إثبات ملكية النطاق عبر DNS TXT
  monitor.py  عامل الفحص المجدول والتنبيهات
  billing.py  Stripe webhook (التحقق من التوقيع وتحديث الباقة)
  mailer.py   إرسال البريد عبر SMTP
  app.py      الموقع ولوحة التحكم (Flask)
tests/        اختبارات لكل ما سبق
```
